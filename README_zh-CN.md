# XRR Layer Studio CPP v2.5.1

这是一个原生 64 位 Windows C++ 程序，用来预览 Bruker D8 Advance 的 XRR 数据、用 FFT 或两点条纹间距估计厚度、根据膜层结构计算模拟曲线，并用 Genetic Algorithm 拟合密度、厚度和粗糙度。程序不需要安装，解压后双击 `XRR_Layer_Studio_CPP_v2.5.1.exe` 即可。

## 当前功能

- 每次打开一个 `.raw` 或 `.txt` 测量文件，程序自动判断格式。
- 支持本项目样例对应的 Bruker `RAW4.00` 二进制文件和带 `[RangeHeader]`、`[Data]` 区段的 TXT 导出文件。
- 横坐标为 `2θ (°)`，纵坐标为真正的对数坐标 `Intensity`。
- 值为 `-9999` 的记录视为未测量：导入时直接跳过，并在曲线中保留缺口，不会把缺口两侧连起来。
- 强度小于或等于零的有效记录会保留在项目和 CSV 中，但不会显示在对数图上。
- 默认 x 范围不再增加左右留白：最小与最大有效 2θ 点分别位于绘图区最左端和最右端。主动勾选 `Show full nominal scan range` 时仍会显示文件声明但尚未测量的名义区间。
- 鼠标滚轮缩放已取消。按住左键拖出矩形选框可同时放大 2θ 和对数强度范围；双击图像、单击 `Reset view` 或按 `R` 恢复完整视图。悬停仍显示 2θ 和强度。
- 按住 `Ctrl` 在实验曲线上依次单击两个点，程序会标出 1/2 号点，并弹窗显示两个 2θ、Δ(2θ)、Δqz 和假设为相邻 Kiessig 条纹时的单层膜厚。
- 原始数据用蓝色实线显示，膜层模拟结果用橙色虚线显示，可用 `Show layer-stack simulation` 隐藏或重新显示。
- 图像侧新增 `FFT thickness`：可指定 2θ 范围，留空时使用全部已测量定义域；结果弹窗绘制厚度频谱并列出候选周期厚度。
- `+ Above / + Below` 会先打开材料选择器。默认是空白自定义层，也可从 118 个常用单质、氧化物、氮化物/碳化物、半导体/功能化合物和磁性合金预设中选择。
- 材料选择器支持类别筛选和按元素符号或英文名称精确查询，例如输入 `Co`、`cobalt` 或 `Si`；选择预设后只填材料与参考密度，厚度和粗糙度仍留空。
- 可在独立弹窗中按参数类型和层级筛选变量、逐项选择本轮拟合的密度、厚度和粗糙度，并自行修改每个变量的上下限。
- 可为每轮拟合指定 `2θ Min / Max`；留空时默认使用全部有效数据点。
- 拟合目标可选择推荐的 `Robust Poisson · high-angle balanced` 或兼容旧行为的 `Pure Poisson deviance`。
- TXT 文件若记录了未单色化的 Cu Kα₂ 波长和比例，模拟与拟合会自动计算 Kα₁/Kα₂ 非相干叠加。
- 导出曲线 PNG 或 SVG 时，会在同一目录自动生成同名 CSV；也可单独导出绘图数据 CSV。CSV 严格只有 `2θ`、实验强度和拟合/模拟强度三列，不写入 `gap_before`、`-9999` 或其他断点列；若层模型尚不完整，第三列保留为空。
- 主界面底部显示 `@KHSO5 All rights reserved.`；该文字不会进入曲线 PNG/SVG，导出整个程序窗口 PNG 时也会自动隐藏。
- 主界面工具栏直接提供 `Open project`；`Reset view` 位于图像一侧，和项目文件操作分区显示。
- 界面采用 Per-Monitor V2 High-DPI 适配：初始窗口、主界面、右侧表格和拟合弹窗按当前 Windows 缩放比例布局，跨显示器时会重建字体并重新排版。右侧膜层区使用更大的专用字号。

## 膜层结构与 XRR 模拟

右侧表格按“最上表面 → 衬底”的顺序排列。最下方 `Substrate` 行固定，不能删除或移动，其厚度固定为空；选中该行时不能在其下方插入新行。可在 Substrate 上方插入最多 256 层薄膜。单击插入按钮后，材料选择器首先选中 `Custom / empty layer`，因此按 Enter 即可保持旧的空层工作流；也可搜索并双击预设。

双击单元格可输入：

- 材料或备注；
- 密度，单位 `g/cm³`；
- 期望厚度，单位 `nm`；
- 粗糙度，单位 `nm`。

粗糙度在主表格、拟合配置和结果弹窗中至少显示三位小数，例如 `0.23` 显示为 `0.230 nm`；这只是显示格式，内部拟合和项目文件仍保留完整数值精度。

数值单元格允许暂时留空。密度必须大于零，薄膜厚度和粗糙度必须大于或等于零。小数请使用英文句点，例如 `12.37`。每行的粗糙度表示该层上表面的界面粗糙度；粗糙度留空时按 0 nm 计算。

材料栏开头需要是化学式，例如 `Ru`、`SiO2` 或 `Co80Tb20`，后面可以继续写备注，例如 `Ru cap`。`Co80Tb20` 按原子比例解释；`Si / native oxide` 会使用开头的 `Si` 计算。只有材料、密度及所有薄膜厚度填写完整后，模拟曲线才会出现。

材料预设中的密度是接近室温的名义块体/晶相参考值，保留三位小数并始终可以编辑。实际沉积薄膜可能因相态、合金配比、孔隙、氧含量或非晶结构而明显偏离该值；预设用于减少查找和录入，不应替代样品本身的密度先验或拟合边界。相态或成分依赖较强的条目会在选择器的 `Reference note` 中提示。

模拟采用自底向上的迭代 Parratt 递推和 Nevot–Croce 界面粗糙度因子，由化学式和质量密度换算电子密度。计算使用导入文件中的 X 射线波长；对于本次 PtCoTb TXT 中的 `Alpha1=1.5406 Å`、`Alpha2=1.54439 Å`、`AlphaRatio=0.5` 且没有单色器/分析器的记录，程序会自动按强度比例叠加双波长结果。模拟点逐点复用导入数据的 2θ 坐标和缺口，因此范围、步长及 `-9999` 未测量区域均与原始数据一致。最后将模拟曲线最大值归一到原始数据的最大强度。

拟合时还会自动估计一个 0–0.050° 的 Gaussian-equivalent 2θ 仪器分辨率 FWHM。该展宽采用稳定的线性时间离散扩散卷积，不跨越 `-9999` 缺口；连续数组由每个 GA 工作线程复用。

未拟合时显示理想镜面反射模拟。膜层表、拟合选择、Poisson 背景模型、仪器展宽、双波长元数据、测量数据和视图会一起保存在 `.xrrproj` 中；v2.5.1 仍能读取 v2.0–v2.5.0 保存的旧项目。材料预设是程序内置的录入辅助，不会改变项目格式；一旦插入，材料与密度和普通手动单元格一样写入项目。

## 图像缩放、两点膜厚与数据导出

在绘图区按住左键并拖动会显示半透明矩形，松开后将该矩形对应的 2θ 与 log(Intensity) 范围放大。小于 8 个逻辑像素的误触不会改变视图，滚轮事件不会缩放。默认和 `Reset view` 状态下，x 轴边界就是第一个与最后一个正强度测量点，不再额外加入 2.5% padding。

按住 `Ctrl` 并在蓝色实验曲线附近单击，程序会吸附到 26 个逻辑像素以内最近的可见实验数据点。第一个点显示紫色 `1`，第二个点显示绿色 `2`；选中第二点后按下式计算：

$$
q_z=\frac{4\pi}{\lambda}\sin\theta,\qquad
t=\frac{2\pi}{|q_{z,2}-q_{z,1}|}.
$$

这里的 2θ 会先精确换算到 qz，并非简单使用小角度近似。结果假设两点是同一单层膜产生的相邻 Kiessig 条纹，即 $\Delta m=1$；如果两点跨过 $N$ 个条纹周期，真实厚度应为弹窗结果的 $N$ 倍。完成一组两点后再次 `Ctrl + 单击` 会开始新的一组。

工具栏 `Export plot` 或 `File → Export plot as PNG/SVG` 在写入图片后，会在图片旁边写入相同主文件名的 `.csv`。例如选择 `sample.png` 会同时得到 `sample.csv`。如果同名 CSV 已存在，程序会在覆盖前单独确认。`File → Export plot data CSV` 仍可只导出数据。

所有绘图数据 CSV 都严格只有三列：

1. `two_theta_deg`；
2. `experimental_intensity`；
3. `fitted_intensity`。

第三列使用完整测量坐标网格上的当前模型曲线，不受图像是否临时隐藏模拟曲线影响。模型不可用时第三列为空。导入时已经排除的 `-9999` 点不会重新出现，曲线缺口也不会作为额外的断点列输出。

发布包中的 `examples/XRR_15min_Ru8_plot_data_v2.5.1.csv` 是用随包 RAW 数据和 Ru/Co80Tb20/SiO2 参考层结构生成的 3,604 行三列示例，可直接检查输出格式。

## FFT 膜厚估计

单击图像侧 `FFT thickness` 或按 `Ctrl+T`，可在弹窗中填写 2θ Minimum、Maximum 和希望显示的最大厚度。两个角度均留空时使用全部正强度测量点，只填一侧时采用单侧范围。程序不会把 `-9999` 缺口两侧连起来。

为了让 FFT 频率直接对应实空间距离，程序先按测量波长将角度换算为

$$
q_z=\frac{4\pi}{\lambda}\sin\theta,\qquad \theta=\frac{2\theta}{2},
$$

再等间距重采样到 $q_z$ 网格，对 $\log_{10} I$ 做二次趋势扣除、稳健异常值限制和 Hann 加窗，最后使用零填充的迭代 radix-2 FFT。若频率为 $f_q$（相对于 $q_z$），候选周期厚度为

$$
t=2\pi f_q.
$$

程序内部 $q_z$ 使用 Å⁻¹，结果换算成 nm。结果窗口同时显示实际 2θ/qz 范围、FFT 点数、由 qz 跨度决定的本征厚度分辨率，以及按相对幅度排序的候选峰。零填充可以让峰位置读数更平滑，但不会提高本征分辨率。

FFT 峰表示界面间距的周期成分，可能对应单层厚度、多层厚度之和/差或高次谐波，并不是唯一的层结构解。建议把峰值作为右侧厚度初值，再结合已知生长结构和 Parratt/GA 拟合确认。

## Genetic Algorithm 拟合

单击右侧 `Fit selected variables...` 或按 `Ctrl+F` 后，程序先弹出本轮拟合配置：

- 每一层的密度 `ρ`、粗糙度 `σ` 和每个薄膜的厚度 `t` 都单独列出；Substrate 没有厚度选项。
- `Parameter` 筛选可切换为全部、仅 Density、仅 Thickness 或仅 Roughness；`Layers` 筛选可切换为全部层、仅薄膜或仅 Substrate。
- `Select shown / Clear shown` 只作用于当前筛选后可见的变量；切换筛选时，暂时隐藏变量的勾选状态和边界不会丢失。弹窗右上角实时显示“当前可见数 / 总数 / 已选总数”。
- 勾选框决定哪些变量参与本轮拟合；未勾选的参数保持不变。
- `Lower` 和 `Upper` 可双击修改。默认是当前值的 `−20% / +20%`；当厚度或粗糙度初值为 0 时，为避免上下限重合，使用 `0–0.2 nm`。
- `Fit 2θ range` 中的 Minimum 和 Maximum 可分别留空；两者均留空时拟合全部有效数据点，只填写一侧时采用单侧范围。范围内少于 8 个可用点时程序会拒绝启动拟合。
- 当前值必须位于上下限之间；密度下限必须大于 0，厚度和粗糙度下限不能小于 0。
- `Objective` 默认选择稳健 Poisson；若需要严格的全局最大似然结果，可切换为 Pure Poisson。
- 一轮最多选择 24 个结构变量。

优化器是实数编码、有边界、多线程的 Genetic Algorithm，包含 tournament selection、BLX 型混合交叉、高斯变异、elitism 和停滞时注入新个体。种群使用连续数组保存，各个个体的 Parratt 计算会并行分配到可用 CPU 核心；搜索阶段最多从指定 2θ 范围内均匀使用 1,500 个有效测量点，最终指标使用该范围内的全部有效点计算，最终绘图曲线则恢复到导入数据的完整坐标网格。

计数误差的基础量仍是 Poisson deviance：

$$
D=2\sum_i\left[\mu_i-y_i+y_i\ln\left(\frac{y_i}{\mu_i}\right)\right],
$$

其中 $y_i$ 是导入强度，$\mu_i$ 是模型期望计数。Pure Poisson 模式直接最小化 $D$。推荐的 Robust Poisson 模式对逐点 deviance residual 使用 Cauchy 损失

$$
L_i=4\ln\left(1+\frac{D_i}{4}\right),
$$

它在残差接近噪声水平时仍保留 Poisson 统计含义，但会限制高计数、低角度的模型失配完全压倒弱的高角度条纹。模型同时自动优化随 $q_z$ 增强的 diffuse-scattering 衰减、恒定 detector-background mean 和仪器展宽；加入这些项后仍会将整条模型曲线最大值严格归一到导入数据最大值。

拟合过程中有进度窗口并可取消。结束后结果弹窗会显示所有拟合参数的“初值 → 结果”、上下限、优化目标、原始 Poisson deviance、拟合范围最高三分之一的 log-RMSE、计算次数、耗时、diffuse 参数、detector mean 和分辨率 FWHM。只有选择 `Apply to layer table` 才会写回右侧表格；选择 `Discard result` 或取消时原表格不会改变。手动修改膜层后，旧的 Poisson 背景参数会自动失效，避免误用。

Diffuse 项是针对一维镜面 XRR 的经验衰减模型，并不是二维 off-specular diffuse scattering 的 DWBA 计算。当前版本已包含双波长和仪器分辨率展宽，但尚未包含复数 SLD 吸收、足迹修正、深度渐变/界面互扩散和参数不确定度估计；密度、厚度和粗糙度可能相关，因此拟合结果应结合合理边界与样品先验判断。

## 日常使用

1. 双击 EXE，或把一个 RAW/TXT 文件拖到程序窗口。
2. 单击 `Open data` 可选择测量文件；单击主界面的 `Open project` 可直接恢复 `.xrrproj` 中的完整工作状态。打开新测量时，现有膜层表会保留。
3. 左键拖框放大感兴趣区间；或按住 `Ctrl` 选择两个相邻条纹点，快速估算单层厚度。
4. 如需对整个范围做频谱分析，单击图像侧 `FFT thickness`；范围留空即分析全部测量域。
5. 在右侧选择一行，用 `+ Above` 或 `+ Below` 插入膜层；在选择器中保留空层或搜索材料预设。参数完整后模拟曲线会自动重算。
6. 单击 `Fit selected variables...`，在弹窗中选择参数和边界，然后启动拟合。
7. 检查结果弹窗；确认后参数才会更新到右侧表格。需要保存数值时使用 `Export plot data CSV`，第三列即当前拟合/模拟曲线。
8. 用 `Save project` 保存完整工作状态。以后可用主界面的 `Open project` 恢复曲线、膜层表、拟合选择、Poisson 项和图像视图。

`examples/XRR_15min_Ru8_reference_fit.xrrproj` 使用已上传 RAW 数据和参考图中的 Ru(8.423 nm)/Co80Tb20(50.428 nm)/SiO2 结构；默认预选两层薄膜的厚度，打开后可直接检查或开始一轮拟合。

参考图中的模拟曲线在高角区明显高于实验曲线，因此这些表格数值不是当前简化物理模型下的严格最优点。参考项目会精确保留图中数值；若同时放开密度、粗糙度等更多参数，遗传算法会按本轮选择的拟合目标继续优化，而不会人为把结果锁定在参考值。

## PtCoTb 实测高角度验证

`PtCoTb.txt` 共含 1,881 个有效点，范围 0.6–10°、步长 0.005°，没有 `-9999`。在图示 Ru/Co80Tb20/Pt/Ta/SiO2 结构下，旧版全范围 Pure Poisson 可能把 detector mean 推到约 6,507 counts，使 6–10° 被整体抬高。v2.3.0 的推荐流程为：

1. 用 Robust Poisson 对全范围厚度与粗糙度拟合；
2. 固定密度，用 6–10° 再拟合一次，将厚度边界收窄至上一轮结果的约 ±3%，粗糙度采用合理先验边界。

验证中 6–8° 与 8–10° 的 log-RMSE 分别达到 0.047 与 0.095 decade。示例项目采用固定密度 Ru 12.379、Co80Tb20 8.397、Pt 21.45、Ta 16.69、SiO2 2.650 g/cm³；这些密度是验证假设，不应替代样品本身的独立信息。对应结果见 `examples/PtCoTb_high_angle_refined_v2.3.0.xrrproj` 与 `docs/PtCoTb_high_angle_validation_v2.3.0.png`。

本文件没有商业代码签名。若 Windows 首次运行时显示 SmartScreen 提示，请先核对随包提供的 SHA-256，再选择“更多信息”→“仍要运行”。

## 从源码构建

需要 Visual Studio 2022 的“使用 C++ 的桌面开发”组件和 CMake。双击 `build_windows.bat`，或在 x64 Native Tools 命令提示符运行它。Release EXE 会生成到 `bin` 文件夹；MSVC 运行库采用静态链接。

## 兼容性说明

本版本面向 Windows 10/11 x64。RAW 是厂商二进制格式；当前解析器针对提供样例中的 `RAW4.00` 结构，遇到不支持或损坏的文件会给出错误提示，不会猜测数据位置。
